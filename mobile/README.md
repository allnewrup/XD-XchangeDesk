# Xchange Desk (mobile app)

The iPhone and Android app for Xchange Desk. It compares estimated exchange rates across 127 UAE exchange houses and banks (about 890 branches), with live market rates, filters, a native map (free, no API key), saved currency pairs, offline last-known rates and directions.

This folder lives in the same repository as the website (the repo root, one level up) but is a **separate project**. They share no code at runtime: the app is React Native (Expo), the website is a Vite web app. Logic that is the same in both (pricing, rate consensus, result sorting) was ported, and the website's server only relays the Yahoo rate feed. Run every command below from this `mobile/` folder.

## Run it on your phone (no Xcode or Android Studio needed)

```bash
npm install
npx expo start
```

Then install **Expo Go** on your phone (App Store / Google Play) and scan the QR code: with the Camera app on iPhone, or inside Expo Go on Android. The phone and the computer must be on the same Wi-Fi.

Other ways to run it:

| Command | Needs |
| --- | --- |
| `npm run ios` | a Mac with Xcode (iOS Simulator) |
| `npm run android` | Android Studio with an emulator |
| `npm run web` | just a browser. A quick preview only: the map is native-only and the Yahoo feed is blocked by browser CORS |

## What is in the app

- **Compare:** currency pair (203 currencies, searchable picker), amount, sell/buy, cash/bank transfer, area, filters (type, open now, emirates), search, "Near me" (distance sorting), pull to refresh, a "Best right now" card and a live market-rate board with its age and source agreement.
- **Provider screen:** the estimate with the market rate, modelled spread and fee; every branch with hours, open/closed and distance; directions; link to reviews on Google Maps.
- **Map:** native map (MapLibre with OpenFreeMap tiles, no API key or billing account) with the matching branches; green pin = best rate; tap a pin for details and directions. Not available in Expo Go (it needs a real build); there the tab lists nearby branches instead.
- **Saved:** favourite pairs with live market rates, plus quick starts.
- **More:** About, How rates are calculated, Data sources and update times (live), Contact, Privacy Policy, Terms of Service.
- **Offline:** the last search, saved pairs and last-known rates are stored on the phone and shown (clearly labelled) when there is no connection.

Not in this version: the AI assistant (the website has one), ratings and reviews (none are invented; there is no licensed source), map language picker, push notifications and widgets.

## Data

- Providers and branches: `src/data/osm-uae.json`, a snapshot of OpenStreetMap (ODbL). To refresh it, regenerate it with the website's script (`node scripts/build-osm-data.mjs` in the repo root) and copy it over: `cp ../src/data/osm-uae.json src/data/`.
- Currency names and flags: `src/data/currency-info.json`, generated by `node scripts/build-currency-info.mjs` (Hermes has no `Intl.DisplayNames`).
- Market rates: four public feeds, cross-checked (`src/lib/fx.js`). Yahoo is relayed through the website's `/api/yahoo` (see `API_BASE` in `src/data/site.js`).
- Provider spreads are **modelled**, not measured; see the in-app "How rates are calculated".

Business details (name, email, operator, policy date, website URL) are in `src/data/site.js`; the legal text is in `src/content.js`.

## Build for the stores

Cloud builds with [EAS](https://docs.expo.dev/build/introduction/) need no local Xcode or Android SDK.

```bash
npm install -g eas-cli
eas login
eas build:configure                      # links the project; writes the project ID into app.json
eas build -p android --profile preview   # installable .apk for testing (free tier)
eas build -p android --profile production  # .aab for Google Play
eas build -p ios --profile production      # needs an Apple Developer account (US$99/year)
eas submit -p ios        # and: eas submit -p android
```

Before the first build, check `app.json`: `ios.bundleIdentifier` and `android.package` are `com.xchangedesk.app`. Change them now if you want another ID, because they cannot change after publishing.

### Before submitting to the App Store / Google Play

1. **Licensed rate data.** The Yahoo endpoint is unofficial and its terms do not allow commercial redistribution. Replace it with a licensed rates API before a store release (`src/lib/fx.js`).
2. **Map:** nothing to set up. OpenFreeMap is a donation-funded free service with no uptime guarantee; for heavy traffic, self-host tiles or switch to a paid provider.
3. **Store listing:** screenshots, description, support URL and privacy policy URL (`https://xd-xchange-desk.vercel.app/privacy`, which has a section covering the app).
4. **Privacy labels:** the app collects no data into its own systems (location stays on the phone). Third parties it contacts are listed in the in-app Privacy Policy.
5. **Apple's "minimum functionality" rule (4.2):** an app must be more than a repackaged website. This one has native maps, location, saved pairs and an offline cache; adding rate alerts (push) or a home-screen widget would make approval safer.
6. **Provider names:** keep the "not affiliated" notices visible; monograms are used, not logos.
7. **Developer account name:** the seller name shown in the store is your personal name unless you enrol as an organisation (requires a registered legal entity and a D-U-N-S number).
